# 📚 BookMonkey

**BookMonkey** is a full-stack web application for buying, selling, and exchanging books. It allows users to browse books, manage a cart and wishlist, place orders, and initiate book exchanges with other users. Built with the MERN stack (MongoDB, Express.js, React.js, and Node.js), it features modern UI and responsive design.

---

## 🚀 Features

- 🔍 Search & filter books by title, author, genre, or language
- 🛒 Add books to cart and place orders
- ❤️ Wishlist functionality
- 🔁 Book exchange system with exchange history and search facility
- 📚 Add and list your own books for sale — become a seller in one click
- 👤 User authentication and profile management
- 📦 Order tracking with expected delivery dates
- 🔧 Manage your own books for sale and for exchange seamlessly

---

## 🛠️ Tech Stack

- **Frontend**: React.js, Bootstrap, MUI
- **Backend**: Node.js, Express.js
- **Database**: MongoDB
- **Deployment**: Localhost (dev); unable to host because my MongoDB Atlas is always showing up some error while connecting.

⚠️ **Important Note**  
> This project runs smoothly on local development environments.  
> Just clone the repository, install the necessary dependencies, and launch both frontend and backend — no additional setup required!
